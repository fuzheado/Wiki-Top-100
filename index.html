WikiTop100 Connections

Interactive visualization of the top 100 most-viewed English Wikipedia articles

How it works

Each day's top 100 is fetched from top.hatnote.com. Every article is then enriched with its categories, outgoing wikilinks, and intro text from the MediaWiki API. A spaCy NLP model extracts named entities (people, organizations, places) from the summaries.

Data pipeline

The graph is built on-the-fly by server.py when you select a date or load the page. Progress is streamed to the UI in real time. API responses are cached locally (24h for the top-100 list, 7 days for article metadata) to reduce load on Wikipedia's servers.

Controls

  • Date picker + ◀ ▶ — navigate between days
  • Search — filter articles by name
  • Ignore — exclude articles from the graph
  • Spacing — adjust node repulsion in the force layout
  • Helpers / Labels / Legend — toggle visibility
  • ⟳ Refresh — clear cache and rebuild the current date
  • Hover a node to highlight its connections
  • Click a node for details and connected articles
  • Drag nodes to reposition; scroll to zoom

Credits

Built with Python (httpx, NetworkX, spaCy), D3.js v7, and the Wikipedia Hatnote API. Data sourced from the MediaWiki API. Top-100 data provided by the hatnote/top project.
